## 🚀 Featured Projects

### 🧠 1. Dynamic Functional Connectivity (dFC) Analysis for Gut–Brain Axis Disorder

**Python | Machine Learning | fMRI Analysis**

An analytical machine learning project exploring dynamic functional connectivity patterns in resting-state fMRI scans to investigate Gut–Brain Axis disorders.

**Key Implementations**

- Analyzed resting-state fMRI scans from 6 subjects.
- Used the Schaefer 2018 brain atlas with 100 brain regions.
- Implemented sliding-window correlation analysis (window size: 30, step: 2).
- Extracted statistical descriptors including mean, variance, entropy and gradient.
- Applied Principal Component Analysis (PCA) for dimensionality reduction.
- Trained an SVM classifier on the reduced feature set.
- Generated connectivity heatmaps, PCA visualizations and ROC curves.

**Technologies**

`Python` `NumPy` `Pandas` `Scikit-learn` `PCA` `SVM` `Matplotlib` `fMRI`

**Project limitation:** The analysis used a small subject count (n=6), limiting the generalizability of the results.

🔗 [View Source Code](https://github.com/revanthhhh123/DFCGut-Brain-Axis-Project)

### ⚙️ 2. Predictive Maintenance Using Machine Learning

**Python | Scikit-learn | Data Analysis**

A machine learning pipeline designed to predict industrial machine failures using sensor parameters and classification algorithms.

**Key Implementations**

- Built a pipeline using a synthetic industrial sensor dataset containing 5,000 samples.
- Analyzed air temperature, process temperature, rotational speed, torque and tool wear.
- Performed exploratory data analysis and feature preprocessing.
- Implemented Logistic Regression, Decision Tree and Random Forest classifiers.
- Compared model performance using classification metrics.
- Performed Random Forest feature importance analysis.

**Model Results**

| Metric | Logistic Regression |
|---|---:|
| Accuracy | 87.7% |
| Precision | 78.9% |
| Recall | 70.6% |

Random Forest feature importance identified tool wear as the dominant predictor, contributing 74.6% of the reported importance.

**Technologies**

`Python` `Pandas` `NumPy` `Scikit-learn` `Logistic Regression` `Decision Tree` `Random Forest`
